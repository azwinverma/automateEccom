# Seller app (Flutter) — Phase 0 foundation

Location: `apps/mobile` · package `commerce_os_seller` · org `np.commerceos` · iOS + Android.
Toolchain: Flutter 3.29.3 / Dart 3.7.2.

## Run

```bash
cd apps/mobile
flutter pub get
flutter run                                   # Android emulator → http://10.0.2.2:8000, iOS sim → http://localhost:8000
flutter run --dart-define=API_BASE_URL=https://api.staging.example.np
```

The client calls `${API_BASE_URL}/api/v1/...` (see `docs/api/phase-0-contract.md`).
Debug Android builds allow cleartext HTTP (debug manifest only); iOS allows local networking only.

## Verify

```bash
flutter gen-l10n      # also runs automatically on pub get / build (flutter.generate: true)
flutter analyze       # strict: strict-casts/inference/raw-types + extra lints
flutter test
```

## Networking rules

| Concern | Where |
|---|---|
| `Authorization: Bearer` | `AuthInterceptor.onRequest` (from in-memory TokenStore) |
| `X-Request-ID` | `RequestContextInterceptor` (UUIDv4 per request; shown as "Ref …" on errors) |
| `X-Merchant-Id` | added to every request unless `extra[ApiExtra.tenant] == false` (auth, `/me`, `POST /merchants`) |
| `Idempotency-Key` | `extra[ApiExtra.idempotent] = true` (generated once, survives refresh retry) or caller-supplied `extra[ApiExtra.idempotencyKey]` (reused across user retries, e.g. onboarding) |
| Refresh | 401 `token_expired` → single-flight `POST /auth/refresh` on a bare Dio; concurrent 401s share one call; a 401 for an already-rotated token just replays |
| Session end | refresh answers 401/403 (`refresh_token_reused`, `session_revoked`, …) → wipe tokens → `SessionSignedOut(reason)` → router sends to login with an explanation |
| Weak network | connect 10s / receive+send 25s; GETs auto-retry twice on connection errors/timeouts; refresh network failures keep tokens; offline banner from connectivity_plus |

## Honesty rules (Phase 0)

Orders, revenue, AI messages, ready-to-ship, exceptions and autopilot have no backend domain yet.
Home renders them as explicit "not counted yet" / empty states. Quick actions open a
"coming in the next release" explainer. No sample or fake numbers anywhere.

## Localization

`en` + `ne`. All UI copy lives in ARB files. Nepali uses Noto Sans Devanagari with line-height 1.7
and Devanagari digits (intl `ne`). Money: `रू १,२५०` / `Rs 1,250` (South Asian grouping, paisa only
when non-zero). Language choice: Settings → App language (persisted in SharedPreferences; best-effort
`PATCH /me {locale}`).
