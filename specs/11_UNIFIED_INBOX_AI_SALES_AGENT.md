# Unified Inbox & AI Sales Agent

> v1 (2026-11-02). The original 11 was never provided. Authored from the build brief; owner review
> required. Built in Phase 2 (Conversation-to-Order).

## Inbox
- **Core:** conversations from supported channels; assignment; labels; SLA timers; customer identity
  resolution; notes; escalation.
- **Context panel:** product context (Product Brain card), order context (status, tracking, COD), and
  the customer timeline.
- **AI:** summary, intent classification, suggested reply, automatic reply (Decision Policy), and
  seller handoff.

**Intents:** product question, stock, size, price, delivery, order, payment, order status,
cancellation, return, exchange, refund, complaint.

## AI Sales Agent: grounded tools only
| Customer says | Agent must call |
|---|---|
| "Black XL available?" | `get_inventory()` |
| "What is the price?" | `get_price()` |
| "Where is my order?" | `get_order()` + `get_tracking()` |
| "I want to return it." | `check_return_eligibility()` |
| "Will it fit me, I'm usually M?" | `get_product_brain()` (size guide, fit facts such as "runs small", return reasons) |

Transactional facts are never generated by the model. If a tool fails, the agent says it will check
and escalates. It never guesses.

## Conversation to order
customer message → AI extraction → product resolution → variant → quantity → name → phone →
structured address (province/district/municipality/ward/area/landmark) → delivery option → payment
(COD or prepaid) → validation → **COD risk assessment** (Phase 6) → customer confirmation → order
created (idempotent on conversation + draft version) → stock reserved.

The agent asks only for missing fields. An ambiguous variant or address becomes an exception, not a
guess.

## Product Brain feedback (Phase 6)
- **FAQs:** repeated questions are clustered per product (embedding + intent) into suggested FAQs. The
  seller approves the answers, and the Sales Agent then uses the approved answers.
- **Pre-sale objections** ("is it true size?", "colour fades?") become Commerce Memory facts linked to
  return insights.
- **Complaint intents** feed Return Intelligence and product quality signals.

## Metrics
- AI resolution rate
- auto-reply rate (an APS component: customer replies)
- chat-to-order conversion
- time to first response
- escalation rate
- wrong-answer reports (eval feedback)
